<p>Este sitio web utiliza «<em>cookies</em>» y/o tecnologías similares que almacenan y recuperan información cuando navegas. </p><p>En general,estas tecnologías pueden servir para finalidades muy diversas, como, por ejemplo,reconocerte como usuario, obtener información sobre tus hábitos de navegación,o personalizar la forma en que se muestra el contenido. </p><p>Según su finalidad esta página web utiliza o utilizará en el corto plazo:</p><ul><li><strong>«<em>Cookies</em>» técnicas</strong>, que te permiten como usuario la navegación a través de esta página web y la utilización de las diferentes opciones o servicios que presta, en especial, para permitirte acceder a partes de acceso restringido.</li><li><strong>«<em>Cookies</em>» de preferencias o personalización</strong>, que permiten recordar tus ajustes personalizados para que accedas al servicio con determinadas características, como, por ejemplo, el idioma, el número de resultados a mostrar cuando el usuario realiza una búsqueda, el aspecto o contenido del servicio en función del tipo de navegador a través del cual el usuario accede al servicio o de la región desde la que accede al servicio, etc</li></ul><p>En la actualidad en esta página web no se utilizan otros tipos de «<em>cookies</em>» como las de análisis o medición o publicidad comportamental.</p><p>Según quién sea la entidad que gestione el equipo o dominio desde donde se envían las «<em>cookies» </em>y trate los datos que se obtengan, esta página web utiliza:</p><ul><li><strong>«<em>Cookies</em>» propias</strong>, enviadas desde un equipo o dominio gestionado por<br>el editor de esta página y desde el que se presta el servicio solicitado por el usuarior.</li></ul><p>En la actualidad en esta página web no se utilizan otros tipos de «<em>cookies</em>» como las de terceros.</p><p>Conforme al artículo 22.2 de la LSSI y la interpretación del GT29, en su <a href="https://ec.europa.eu/justice/article-29/documentation/opinion-recommendation/files/2012/wp194_en.pdf">Dictamen 4/2012</a> no es necesario informar y obtener el consentimiento sobre el uso de las siguientes «<em>cookies</em>» que utiliza este sitio web:</p><ul><li>«<em>Cookies</em>» de autenticación o identificación de usuario (únicamente de sesión)</li><li>«<em>Cookies</em>» de personalización de la interfaz de usuario.</li></ul><p>Por eso no verás ningún «<em>banner</em>» molesto que te impida disfrutar de la página.</p>
